# Анализ архитектурных стилей

## Топ-3 сквозные характеристики системы

1. **Availability** (6 BC) — почти вся система должна работать без сбоев
2. **Testability** (6 BC) — нужно хорошее покрытие тестами
3. **Securability** (5 BC) + **Consistency** (5 BC) — защита данных и консистентность
