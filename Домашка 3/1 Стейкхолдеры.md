# Cтейкхолдеры и их консерны

### Топ-менеджмент
- **Скоринг (Testing) как продукт**: логика отбора воркеров сложнее, чем планировалось; хотят продавать алгоритм другим компаниям
- **Разные релизные циклы**: основная система — раз в месяц, скоринг (Testing) — раз в неделю
- **Низкий TTM**: быстро выйти на рынок
- **Проверка гипотез**: критично быстро тестировать новые гипотезы по отсеву котов (US-110)
- **Матчинг (Matching)**: использовать внутри компании, US-060 отменён — разработчики переучились

### Клиенты
- **Надёжность**: система без сбоев и тупняков
- **Прозрачность**: видеть список услуг, инвойсов, статусов оплат
- **Скидки**: корректный расчёт скидок (US-040)

### Воркеры
- **Выплаты**: получать 60% от стоимости, штрафы за провалы
- **Задания**: видеть список активных и завершённых услуг
- **Уведомления**: получать информацию о заказах

### Менеджеры
- **Секретность ставок**: скрыть систему ставок от других отделов, разработчиков и начальства
- **Управление тестами**: конфигурировать набор тестов под каждого кота (US-110)
- **Проверка качества**: случайно выбирать заказы для проверки (US-190-210)
- **Анализ провалов**: понимать, что случилось, связываться с клиентом (US-200)
- **Форма гипотез**: заносить результаты проверки качества для улучшения бизнеса (US-210)

### Разработчики матчинга
- **Автономия реализации**: сами реализуют алгоритм на любом языке (US-300)
- **Гибкость алгоритма**: возможность добавлять/редактировать шаги (US-300)
- **Секретность формулы**: не хотят раскрывать внутренние детали расчёта рейтингов
- **Интеграция через контракт**: чёткий интерфейс входа/выхода (Задача + Эталонный образец → Лучший кандидат + Стоимость)
- **US-060 отменён**: теперь используют общий язык с системой, но сохраняют автономию реализации

### Админы
- **Мониторинг**: простота мониторинга для своевременного обнаружения сбоев
- **Не авральный режим**: замечать проблемы до того, как они станут критичными
- **DDoS-атаки**: мониторинг атак на систему тестирования (US-081)

### Финотдел
- **Списание раз в месяц**: слишком затратно списывать каждую неделю (изменение US-220)
- **Новые способы оплаты**: постоянно добавлять новые методы списания
- **Сохранность данных**: боятся потерять финансовую информацию
- **Выплаты воркерам**: продолжать платить раз в месяц через "Золотую шляпу"

### Юристы
- **CatFinComplience**: особый способ хранения данных
- **Наблюдаемость**: особая наблюдаемость за системой
- **Правовые нормы**: соответствие всей системы законодательству

### Отдел сборки расходников
- **Уведомления**: получать информацию о новом заказе
- **Кнопка "выдано"**: простой интерфейс (US-160)
